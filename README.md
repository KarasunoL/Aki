Learn. Remember. Repeat.

## About

Aki is a modern, offline-first flashcard application designed to make studying simple, organized, and distraction-free.

Built with **Python** and **PySide6**, Aki lets you organize flashcards into folders, review them with a clean interface, and focus on learning without unnecessary complexity.

Whether you're preparing for exams, learning a new language, or memorizing anything else, Aki provides a fast and enjoyable study experience.

---

## Features

* 📁 Organize flashcards into folders
* 📝 Create and edit flashcards with ease
* 🔍 Browse and search your study collections
* 💻 Beautiful modern desktop interface
* ⚡ Fast and lightweight performance
* 💾 Offline-first experience
* 🎨 Clean black & white inspired design
* 🖥 Cross-platform support (Windows, Linux & macOS)
* ❤️ Built with simplicity in mind
